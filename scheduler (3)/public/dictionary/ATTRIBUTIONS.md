# Dictionary data

English definitions are stored in the existing compressed English shards.

Vietnamese translations were imported from the AVDict English-Vietnamese raw dictionary:
https://github.com/yenthanh132/avdict-database-sqlite-converter

The source README identifies the original dictionary source as the Leipzig English-Vietnamese dictionary. The import script is `scripts/download-vietnamese-dictionary.cjs` and can regenerate the Vietnamese shards without using an AI service.
